# МаркетГрад — облачная инфраструктура (курс по облачным сетям)

Учебный проект: проектирование облачной инфраструктуры для интернет-магазина «МаркетГрад» — витрина, REST API, поиск, PostgreSQL и Redis, развёрнутые в VPC `10.20.0.0/16` на три зоны доступности с балансировкой через ALB, зональными NAT Gateway и гибридной связностью с on-premise ДЦ (Direct Connect + Site-to-Site VPN).

Репозиторий заводится один раз и пополняется по мере прохождения курса: каждая лабораторная добавляет свою папку и раздел.
